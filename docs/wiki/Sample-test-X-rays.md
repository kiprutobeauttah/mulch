# Sample test X-rays

The `testxrays/` directory in the repository contains sample chest X-rays you can use to try Mulch without your own images:

| File | Source |
| --- | --- |
| `IM-0005-0001.jpeg` | Frontal chest radiograph (sample film) |
| `IM-0168-0001.jpeg` | Frontal chest radiograph (sample film) |
| `person100_bacteria_475.jpeg` | Pneumonia (bacteria) sample |
| `person100_bacteria_478.jpeg` | Pneumonia (bacteria) sample |
| `person103_bacteria_489.jpeg` | Pneumonia (bacteria) sample |

Upload any of these in **New assessment** and run the analysis. The pneumonia samples are for testing the PNEUMONIA path; compare the diagnosis and attention heatmap against the normal films.

Mulch is a decision-support aid only and is not a substitute for professional clinical diagnosis.
